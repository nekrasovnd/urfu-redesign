# Логотип

Обновлённый знак «Точная У» и лок-апы. Все надписи переведены в кривые (Golos Text SemiBold), файлы не зависят от шрифтов. Исходник — скрипт `tools/build-logo.mjs` в репозитории проекта.

| Файл | Цвета | Когда |
|---|---|---|
| `urfu-short-ru-color.svg` | знак `#e50046`, текст `#1d1d1b` | основная версия на светлом: шапка десктопа, презентации |
| `urfu-short-ru-white.svg` | всё `#ffffff` | на графите, синем `#174496`, красном `#e50046` |
| `urfu-full-ru-color.svg` / `-white.svg` | как выше | с нижним блоком «имени первого Президента России Б.Н. Ельцина»: футер, документы, вывески |
| `urfu-abbr-color.svg` | знак `#e50046`, текст `#1d1d1b` | «УрФУ»: шапка на телефоне, соцсети |
| `urfu-short-en-color.svg` | как короткая | англоязычная версия |
| `urfu-sign-color.svg` / `-white.svg` | `#e50046` / `#ffffff` | знак отдельно: аватары, паттерны, анимация |
| `favicon.svg`, `app-icon.svg` | белый знак на `#e50046` | вкладка браузера (32), иконка приложения (512) |
| `construction.svg` | — | построение знака на сетке с наклоном 1:2 |

Охранное поле — две x-высоты верхнего блока (≈ 0,36 высоты знака). Минимум: короткая версия 100 px, аббревиатура 56 px, знак 16 px. Цветную версию нельзя ставить на красный фон; «галочку» нельзя убирать.
