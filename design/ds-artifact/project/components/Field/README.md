# Field

Поле формы: подпись, контрол, подсказка и ошибка.

- Обёртка `.field`, подпись `.field__label` всегда видима (плейсхолдер — только пример ввода).
- `.input`, `.select` — высота 52 px, рамка 2 px `rule`, фон `surface`, скругление `radius-s`.
- `.input--score` — поле балла ЕГЭ: крупные табличные цифры Unbounded.
- Ошибка: `aria-invalid="true"` на поле + `.field__error` с объяснением, что исправить.
- `.check` — чекбокс с синей заливкой в отмеченном состоянии.
