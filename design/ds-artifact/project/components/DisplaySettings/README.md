# DisplaySettings

Настройки отображения — замена отдельной «версии для слабовидящих». Открываются значком-глазом (`.icon-btn`) в шапке на каждой странице.

- Панель `.megamenu.a11y-panel` открывается тем же механизмом, что и мега-меню. Внутри — строки `.a11y-row`: подпись `label` и переключатель `.segmented`.
- Четыре настройки, каждая — атрибут на `<html>`: размер текста `data-text="l|xl"` (увеличивает токены `fs-*`), цвета — тема `data-theme` или `data-contrast="high"` (чёрное на белом), интервалы `data-spacing="wide"`, анимация `data-motion="off"`.
- Настройки запоминаются в браузере и применяются скриптом в `<head>` до первой отрисовки — страница не мигает. Кнопка «Сбросить» возвращает всё как в системе.
- Бенчмарк 19 вузов: значок-глаз или версию для слабовидящих показывают не меньше 16 — жюри ищет его по привычке.
