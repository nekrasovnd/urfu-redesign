# ProgramCard

Карточка образовательной программы в каталоге и в подборе по баллам.

- Порядок всегда одинаковый: код и институт → название → уровень, форма, срок → экзамены с минимальными баллами → цена и статус приёма.
- Код — `accent-text` Unbounded, название — H3. Экзамены — `.tag--soft`, альтернатива пишется словами («Информатика ≥ 46 или физика ≥ 41»).
- Цена — «до 390 000 ₽/год»; если цены нет в источнике — «Стоимость уточняется», не прочерк.
- Вся карточка — одна ссылка; при наведении сдвигается с `shadow-pop`.
