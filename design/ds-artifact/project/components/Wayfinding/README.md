# Wayfinding

Хлебные крошки, вкладки и пагинация.

- `.breadcrumbs` — на всех страницах глубже первого уровня, разделитель «/», последний пункт без ссылки с `aria-current="page"`.
- `.tabs` — вкладки внутри страницы (карточка программы, институт). Активная — подчёркивание `accent` 4 px. На телефоне прокручиваются по горизонтали.
- `.pagination` — текущая страница графитовым квадратом, зоны 44 × 44 px.
