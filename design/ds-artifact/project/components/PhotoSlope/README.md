# PhotoSlope

Два способа поставить фото в фирменный язык.

- `.photo-slope` — снимок в срезе 1:2: обёртка наклонена на `slope`, картинка внутри — с обратным наклоном, поэтому сама фотография не искажается. `.photo-slope--tint` переводит снимок в фирменный синий (grayscale + multiply по `accent`).
- `.photo-bg` — фото подложкой под тёмную плашку (плитка кампуса, обложка вуза). Затемнение — градиентом поверх, текст только белый.
- Только реальные фото УрФУ: пресс-служба или Wikimedia Commons со свободной лицензией. Подпись `.photo-credit` с автором и лицензией обязательна.
