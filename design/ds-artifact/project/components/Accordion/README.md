# Accordion

Вопросы и ответы, длинные условия — на `<details>`/`<summary>`.

- Начинается с `rule-thick`, пункты разделены `rule-thin`, высота заголовка от 64 px.
- Стрелка-шеврон поворачивается при открытии. Первый пункт можно открыть по умолчанию.
- Вопрос формулируется так, как его задал бы абитуриент.
