# ActionList

Список быстрых действий — главный элемент хабов и первого экрана главной.

- Контейнер `.action-list` начинается с линейки `rule-thick`, строки `.action` разделены `rule-thin`, высота от 64 px.
- Первая строка может быть `.action--primary` (красная) — это главное действие роли.
- Вторая строчка `<small>` — уточнение: число направлений, телефон, срок.
- При наведении строка инвертируется в графит и сдвигается вправо.
- Не больше 6 строк; если действий больше — это уже меню раздела.
