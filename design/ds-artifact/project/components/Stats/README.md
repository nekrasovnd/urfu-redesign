# Stats

Ряд крупных цифр между толстыми линейками.

- `.stats` — сетка, `.stat__value` — стиль `stat` (Unbounded 800, табличные цифры), `.stat__label` — что это за число, до 22 знаков в строке.
- `.stat--accent` красит одну цифру в `accent` — самую важную для страницы.
- Только реальные числа с источником (например, страница «УрФУ в цифрах»). Не больше четырёх в ряд.
