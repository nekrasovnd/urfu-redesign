# Diagonal

Фирменная диагональ: синяя плашка, срезанная под наклоном знака «У».

- Класс `.diagonal` на секции добавляет плашку `accent` справа, скошенную на `slope` (−26,565°, наклон 1:2).
- `.diagonal--rule` — вместо плашки тонкая графитовая линейка под тем же углом.
- Одна диагональ на экран, только в первом экране главной и хабов разделов. Текст не заходит на плашку: ограничивайте ширину заголовка (`max-width: 14ch`).
