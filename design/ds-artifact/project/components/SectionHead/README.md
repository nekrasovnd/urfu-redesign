# SectionHead

Заголовок раздела страницы: номер, заголовок и ссылка «ещё» над толстой линейкой.

- `.section-head` начинается с `rule-thick`. Номер `.section-head__index` — `accent-text`, только если разделы действительно идут по порядку (шаги поступления, главы лонгрида); на главной номер не ставится.
- Заголовок — стиль H2. Ссылка справа — `.btn--ghost`.
- На телефоне элементы складываются в столбик.
