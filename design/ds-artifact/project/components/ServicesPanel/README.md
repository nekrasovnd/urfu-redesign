# ServicesPanel

«Все сервисы УрФУ» — один вход в поддомены университета, открывается кнопкой-сеткой в шапке. Решение из бенчмарка («Сайты ТГУ») для главной боли аудита: с главной urfu.ru ведут 38 поддоменов, у каждого свой дизайн.

- Панель `.megamenu.services-panel`: лид и языки слева, четыре группы по задачам — Учёба, Поступление, Жизнь и карьера, Сотрудникам и партнёрам.
- Строка `.services-panel__list a` — название сервиса и его адрес `small`, чтобы человек видел, куда уходит. Ссылки открываются в новой вкладке.
- Подписи и адреса — как на urfu.ru, никаких придуманных сервисов. Сами поддомены не ломаем: панель работает, пока они переезжают в основной сайт.
- На телефоне кнопка-сетка скрыта, сервисы — пунктом мобильного меню; все сервисы находит и поиск ⌘K.
