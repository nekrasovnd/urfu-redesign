# Tags

Метки, фильтр-чипы и статусы.

- `.tag` — неинтерактивная метка: уровень, форма обучения. `.tag--accent` — одна важная метка («Бюджет»), `.tag--soft` — фоновая (экзамены в карточке).
- `.chip` — фильтр, кнопка с `aria-pressed`. В нажатом состоянии — графит. `.count` — число результатов.
- `.status--open` / `--soon` / `--closed` — точка + текст. Статус никогда не передаётся одним цветом.
