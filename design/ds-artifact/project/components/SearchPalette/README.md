# SearchPalette

Поиск по сайту по ⌘K или «/» — равноправная навигация.

- Модальное окно с рамкой `rule-thick` и плакатной тенью `shadow-pop`, поле 64 px.
- Результаты по группам: программы, люди, места, страницы, сервисы, группы расписания. Выбранный результат — графит.
- Пустой запрос показывает частые задачи выбранной роли. Управление стрелками, Enter, Esc.
