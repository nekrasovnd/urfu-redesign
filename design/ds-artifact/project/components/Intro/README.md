# Intro

Обложка вуза — первый экран главной: фото главного корпуса во всю ширину, белый знак «У», название и четыре проверенные цифры. Появилась по отзывам студентов на прототип: «сначала хочется увидеть сам университет», «главная перегружена, как старая».

- `.intro` — секция во всю ширину, `min-height` от 520 до 760 px; фото `.intro__photo` лежит подложкой, поверх — затемнение фирменным тёмно-синим снизу и слева, текст всегда белый.
- `.intro__title` — полное название Unbounded 800, где первая буква — сам знак `.intro__u`, как в аббревиатуре логотипа (знак + «рФУ»): основной штрих равен высоте заглавной (0,75 em), хвост уходит под строку. Знак красный — «полноцветное на тёмном». Отдельный знак над заголовком убран: четыре «У» подряд (логотип, знак, «Уральский», «университет») бросались в глаза. Для скринридера название продублировано обычным текстом. `.intro__sub` — имя Б.Н. Ельцина, город, год основания.
- `.intro__stats` — четыре цифры стилем `stat` под линейкой 3 px; на планшете и телефоне — сетка 2 × 2.
- `.intro__credit` — подпись к фото с автором и лицензией (для снимков Wikimedia Commons это обязательно).
- Только реальные цифры из «УрФУ в цифрах»; на телефоне отдаётся облегчённое фото (`<source>` 900 px).
