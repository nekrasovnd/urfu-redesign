# NewsCard

Карточка новости в ленте и на главной.

- Фото 3:2 без скруглений, мета (дата · рубрика), заголовок Golos 600 20 px, подзаголовок `fg-muted`.
- Заголовок подчёркивается `link-underline` при наведении на всю карточку; фото слегка увеличивается.
- Подпись к фото и `alt` обязательны. Без фото карточка остаётся текстовой — без серой заглушки.
