# Table

Таблица данных: расписание, сравнение программ, стоимость.

- Заголовки колонок — стиль `label` над линейкой `rule-thick`, строки через `rule-soft`, наведение — `surface-2`.
- Цифры табличные. Широкая таблица прокручивается внутри `.table-wrap`, страница — никогда.
- На телефоне расписание показывается списком карточек, а не таблицей.
