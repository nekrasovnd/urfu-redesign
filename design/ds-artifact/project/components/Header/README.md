# Header

Шапка сайта с пятью разделами и мега-меню.

- Слева логотип (короткая версия, высота 44 px; на телефоне — аббревиатура 36 px), пять разделов: Поступление, Обучение, Наука, Жизнь в УрФУ, Об университете. Справа поиск ⌘K, кнопки-иконки 44 × 44 (`.icon-btn`): глаз — настройки отображения, сетка — «Все сервисы УрФУ», затем EN · 中文 (ведут на действующие версии urfu.ru, помечены ↗) и «Личный кабинет». Открытая кнопка-иконка инверсная.
- Шапка липкая, под ней `rule-thick`. Активный раздел подчёркнут `accent` 3 px.
- Мега-меню открывается по клику (не по наведению) и работает с клавиатуры. Три зоны: лид и два главных действия, полный список раздела в две колонки (не больше 13 пунктов), промо-плашка `surface-inverse` с ближайшим событием или дедлайном.
- Панели настроек и сервисов открываются тем же механизмом, что и мега-меню: клик, Esc, клик мимо.
- Ниже 1400 px языки уходят в панель сервисов, ниже 1100 px разделы прячутся в кнопку «Меню», на телефоне сетка сервисов — пунктом меню.
