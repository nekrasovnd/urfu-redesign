# Header

Шапка сайта с пятью разделами и мега-меню.

- Слева логотип (короткая версия, высота 44 px; на телефоне — аббревиатура 36 px), пять разделов: Поступление, Обучение, Наука, Жизнь в УрФУ, Об университете. Справа поиск ⌘K и «Личный кабинет».
- Шапка липкая, под ней `rule-thick`. Активный раздел подчёркнут `accent` 3 px.
- Мега-меню открывается по клику (не по наведению) и работает с клавиатуры. Три зоны: лид и два главных действия, полный список раздела в две колонки (не больше 13 пунктов), промо-плашка `surface-inverse` с ближайшим событием или дедлайном.
- Ниже 1100 px разделы прячутся в кнопку «Меню» (полноэкранное меню с переключателем роли).
