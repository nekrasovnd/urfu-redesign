# RoleSwitch

Переключатель роли «Я — …» на главной и в мобильном меню.

- `.segmented` — группа кнопок с `aria-pressed`; выбранная — графит.
- Роль перестраивает список быстрых действий (`ActionList`), но не навигацию: структура сайта одна для всех.
- Роли: абитуриент, студент, сотрудник, школьник, партнёр, выпускник, СМИ. На телефоне показываются первые четыре, остальные — в меню.
- Выбор сохраняется в браузере и не требует входа.
