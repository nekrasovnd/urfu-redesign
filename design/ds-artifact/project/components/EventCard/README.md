# EventCard

Строка события в афише: дата плакатным блоком слева.

- `.card-event__day` — день стилем Unbounded 800, `.card-event__month` — три буквы капсом.
- Справа — название и мета: даты интервала, тип, статус регистрации.
- События идут списком через `rule-thin`; для календаря на месяц используется тот же блок даты.
