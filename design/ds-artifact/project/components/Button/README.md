# Button

Кнопка — главное и второстепенные действия; ссылка — переход внутри текста.

- `.btn--primary` (красная заливка `accent`) — одно главное действие на экран: «Подобрать программу», «Подать документы».
- `.btn--ink` (графит) — сильное второе действие рядом с главным или на красной плашке.
- `.btn` (рамка 2 px) — обычные действия. `.btn--ghost` — третьестепенные, выглядят как ссылка.
- Размеры: `.btn--sm` 36 px, обычная 48 px, `.btn--lg` 60 px.
- Текст — глагол и объект. Стрелка `<span class="arrow">→</span>` только у кнопок, которые ведут дальше по пути.
- `.link` — ссылка в тексте: цвет текста `link`, подчёркивание `link-underline` 2 px, 4 px при наведении.
- `.kbd` — клавиши (⌘K, Esc).

Потребитель передаёт: элемент `<a>` для перехода и `<button>` для действия на месте.
