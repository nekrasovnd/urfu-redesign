# Редизайн сайта УрФУ · «Конструктив»

Конкурсная работа «Взломай веб-дизайн университета» (октябрь 2026): новая структура и навигация urfu.ru, обновлённый логотип, дизайн-система и работающий прототип — главная и 10 страниц разных типов на реальных данных университета.

## Что внутри

| Папка | Что |
|---|---|
| [`site/`](site/) | Прототип сайта на Astro: главная, подбор программы по баллам ЕГЭ, каталог и карточка программы, расписание, хаб студента, новости и статья, афиша, институт, кампус |
| [`design/system/`](design/system/) | Дизайн-система: токены (`tokens.css`), компоненты (`components.css`), страница-спецификация |
| [`design/logo/`](design/logo/LOGO.md) | Обновлённый знак «Точная У» и все версии логотипа в SVG |
| [`content/`](content/) | Реальный контент, собранный с urfu.ru: 907 программ, пороги ЕГЭ, новости, институты, расписание |
| [`research/`](research/) | Аудит текущего сайта, разбор брендбука, новая информационная архитектура |
| [`tools/`](tools/build-logo.mjs) | Генератор логотипа: надписи в кривых из Golos Text |

## Запуск

```bash
cd site
npm install
npm run dev
```

Сайт откроется на http://localhost:4321. Публикация на GitHub Pages — автоматически при пуше в `main` (`.github/workflows/deploy.yml`).
